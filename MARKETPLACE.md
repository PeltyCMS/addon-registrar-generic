Domain availability, register, renew, transfer and nameserver updates through the official Generic HTTP registrar API. Prices sync into Pelty TLD pricing; orders provision automatically.

### Features
- Availability + premium checks
- Register / renew / transfer
- Nameserver + contact updates
- Sandboxed WASM registrar module

### Requirements
- PeltyCMS domain module
- Generic HTTP registrar reseller API access
